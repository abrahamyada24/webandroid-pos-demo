Paket Starter (gratis). Folder Google Drive berisi file APK versi terbaru.

Cara memasang

  1. Unduh file APK di atas dari HP Android Anda. Jika dibuka di Google Drive, pilih file APK lalu tekan Download.
  2. Buka file yang terunduh. Jika diminta, izinkan “Instal dari sumber ini” untuk browser Anda (Pengaturan → Keamanan / Aplikasi).
  3. Jika muncul peringatan Play Protect, pilih “Tetap instal”. Peringatan ini muncul karena aplikasi belum dari Play Store.
  4. Buka LitePOS, lalu masuk atau aktifkan langganan Anda.
